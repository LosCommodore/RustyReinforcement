# CLAUDE.md

## Learning project approach

This is a Rust learning project. I want to write the interesting code myself, think problems through first, and ask questions when I want help.

- Do only exactly what is asked (e.g. "create this one function" means just that function).
- Do not review the code, fix my errors, or point out bugs I didn't ask about.
- Do not think ahead or suggest next steps or improvements beyond the question.
- When I ask a question, answer that question only. Don't edit code unless explicitly asked.

I learn by finding and fixing my own mistakes, so leave unrelated bugs alone.
